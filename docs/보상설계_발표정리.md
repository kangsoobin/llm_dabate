# 보상 설계 정리 — 발표자료 참고용

> 컨퍼런스 최종 발표 슬라이드 제작 시 참고할 수 있도록, GRPO self-play 강화학습의
> 보상 설계 전체(문제의식 → 설계 → 검증 → 실측)를 한 문서로 정리한 것.
> 상세 설계 문서는 [`reward_design_v2.md`](reward_design_v2.md), 실행 방법은 [`../HANDOFF.md`](../HANDOFF.md) §3 참고.
> 작성: 2026-07-04.

---

## 1. 한눈에 보기 — 전체 학습 파이프라인

```
[Phase 1. SFT]                       [Phase 2. GRPO self-play RL]
페르소나 데이터 2,000개/side          ┌────────────────────────────────────┐
  → QLoRA로 성향을 가중치에 내재화     │ 1. self-play: LEFT vs RIGHT가       │
  → adapters/left, adapters/right    │    실제 멀티라운드 토론 (vLLM 배치)   │
     (완료: loss 2.05→0.17 / 0.97)   │ 2. 턴 단위로 잘라 GRPO 데이터셋 구성  │
                                     │ 3. 같은 컨텍스트에서 G=8개 재샘플링    │
                                     │    → 그룹 내 상대평가(advantage)     │
                                     │ 4. judge-free 보상 5종 가중합         │
                                     └────────────────────────────────────┘
```

- **SFT가 푸는 문제**: 시스템 프롬프트만으로는 토론이 길어질수록 base model의 중립 성향으로
  회귀(Default Bias). 가중치 자체에 성향을 내재화.
- **GRPO가 푸는 문제**: SFT는 "페르소나 유지"까지만. **라운드를 거치며 좋은 토론이 되는가**
  (동조하지 않고, 논점을 회피하지 않고, 같은 말을 반복하지 않는가)는 보상으로만 최적화 가능.

## 2. 문제의식 — MAD 실패 유형과 보상의 매핑 (중간발표 슬라이드 13 확장)

| MAD 실패 유형 | 증상 | 대응 보상 | 근거 연구 |
|---|---|---|---|
| Sycophancy (동조) | 상대 주장에 설득되어 입장이 흔들림 | **R_persona** (동조 페널티) | Peacemaker or Troublemaker (arXiv:2509.23055) |
| Default Bias (중립 회귀) | 라운드가 갈수록 양시론으로 수렴 | **R_persona** (anchor 유지 보상) | Systematic Biases in LLM Simulations of Debates |
| 논점 회피 | 상대 논점을 안 다루고 자기 말만 반복 | **R_engagement** (key-point 커버리지) | ArgKP/KPA (ACL 2021 argmining) |
| Echo Chamber / DoT | 두 agent가 서로 수렴, 조기 합의 | **R_diversity** (유사도 페널티) | Encouraging Divergent Thinking (arXiv:2305.19118), Diversity Collapse (arXiv:2604.18005) |
| 표면적 자기 반복 | 같은 문구 복붙 | **R_novelty** (Jaccard 안전망) | — (v1 원안 계승) |
| 근거 없는 주장 | hallucination 전파 | R_grounding (RAG 연동 전 비활성) | DebateSum (ACL 2020), VERI-DPO |
| Judge Ceiling | judge 능력이 시스템 상한 | **보상에서 judge 의존 제거** (아래 §3) | Judging with Many Minds (arXiv:2505.19477) |
| Tyranny of Majority | 다수결이 소수 의견 묵살 | 아키텍처로 해결(2-agent, voting 없음) | Debate or Vote (arXiv:2508.17536) |

## 3. v1 원안 → v2 재설계: 무엇을 왜 바꿨나

v1 원안(보상 설계.pdf): 성향 점수 `S(y)` 직접 보상 + judge 반박품질 `Q(y)` + Jaccard 반복 페널티.

| 문제 | v1 | v2의 해결 |
|---|---|---|
| **극단화 유인** | LEFT는 `-S(y)`를 그대로 보상 → 논증 없이 극단적 어휘만 써도 보상 증가 (reward hacking) | anchor(SFT seed 응답 임베딩 평균)와의 유사도를 [0,1]로 **clip** — "기준 페르소나에서 벗어나지 않았는가"만 보고, 더 극단적이어도 추가 보상 없음 |
| **Judge Ceiling이 학습 신호에 유입** | 3개 보상 중 2개가 외부 LLM judge 의존 | 전 컴포넌트를 **judge-free**(임베딩·형태소 매칭)로 재설계. judge는 선택적 보조 신호(기본 꺼짐) + 학습 후 평가용으로만 |
| 상대와의 수렴을 못 잡음 | 자기 반복만 페널티 | R_diversity가 상대 발언과의 유사도도 페널티 |

관련 근거: PReSS (arXiv:2504.17052) — 페르소나 프롬프팅과 내재 편향 충돌 시 응답 과장·불안정,
The Confident Liar (arXiv:2606.10296) — LLM judge는 자신감 있는 오답에 취약.

## 4. v2 보상 컴포넌트 (기본 가중치: 1.0 / 1.0 / 0.8 / 0.5 / 0.0)

### 4.1 R_persona — 페르소나 일관성 + 항동조 (w=1.0)

```
drift      = clip(cos(E(y), anchor), 0, 1)            # anchor = SFT seed 응답 임베딩 평균
sycophancy = cos(E(y), E(opp_now)) - cos(E(y_prev), E(opp_now))   # 상대 쪽으로 이동량
gate       = 1 - coverage(opp, y)                     # 논점을 다루며 가까워졌으면 완화
R_persona  = drift - λ_syc · max(0, sycophancy) · gate
```

- **coverage 게이트가 v2 정비(07-04)의 핵심 추가점**: 상대 쪽으로의 모든 수렴이 동조는 아니다 —
  정당한 반박·부분 수용도 수렴으로 측정됨 (*Not All Flips Are Conformity*, arXiv:2606.00820).
  상대 논점을 정면으로 다루면서(coverage↑) 가까워진 것은 교전이므로 페널티 완화, 논점을
  회피하며 가까워진 것(순수 동조)만 강하게 처벌.

### 4.2 R_engagement — 반박 참여도 (w=1.0)

```
KP(opp)    = 상대 발언에서 형태소 분석(kiwi) 기반 명사 빈도 상위 8개
coverage   = |KP(opp) ∩ terms(y)| / |KP(opp)|
```

- ArgKP/KPA(ACL 2021)의 경량 근사. judge를 쓰면 1~5점 정면반박 평가를 혼합 가능(기본 꺼짐).
- **한국어 함정(발표 포인트)**: 어절 단위 매칭은 조사 때문에 "최저임금을"≠"최저임금이"로 갈라져
  커버리지가 사실상 노이즈가 됨 → kiwipiepy 형태소 분석으로 교체 후 유의미한 신호가 됨 (§6 실측).

### 4.3 R_diversity — 반-에코챔버 (w=0.8)

```
R_diversity = 1 - max( cos(E(y), E(opp)), max_{과거 자기 발언} cos(E(y), E(past)) )
```

- 상대와의 수렴(조기 합의)과 의미적 자기 반복을 하나로 잡음. "다른 단어로 같은 말"은
  Jaccard(R_novelty)가 못 잡고 임베딩이 잡는다 — 상호보완.

### 4.4 R_novelty — 표면 반복 안전망 (w=0.5, v1 계승)

```
J = 자기 히스토리와의 형태소 Jaccard;  J ≥ τ(0.25)일 때만  -γ(1.5)·(J-τ)
```

### 4.5 R_grounding — 근거 충실도 (w=0.0, RAG 연동 전 비활성)

evidence가 주어지면 NLI entailment 점수. AI-Hub 국회 회의록 데이터(44,033 QA쌍)에 BM25
검색만 붙이면 활성화 가능 — 향후 과제.

## 5. GRPO 학습 구조

```
L_GRPO(θ) = (1/M) Σ_i [ min( r_i·A_i, clip(r_i, 1±ε)·A_i ) ] − β·D_KL(π_θ ‖ π_ref)
A_i = (R_total(y_i) − mean(R_group)) / std(R_group)     # 그룹(G=8) 내 상대평가
```

- **turn-level self-play rollout**: LEFT/RIGHT가 실제 멀티라운드 토론한 트랜스크립트를 턴
  단위로 잘라, 각 턴의 "생성 직전 컨텍스트"에서 8개 응답을 재샘플링 → 그룹 내 상대평가.
  단일턴 Q&A가 아니라 진짜 토론 문맥에서 학습.
- π_ref는 LoRA 어댑터를 끈 base 모델 (별도 ref 모델 복제 불필요 — VRAM 절약).
- 하이퍼파라미터: G=8, lr 1e-5, β(KL)=0.04, ε(clip)=0.2, 1 epoch.
- off-policy 완화: 학습 후 갱신된 어댑터로 트랜스크립트를 재생성해 1~2회 반복하는
  iterative self-play 권장 — MAPoRL(ACL 2025, arXiv:2502.18439) co-training의 경량 근사.

## 6. 설계 검증 — "보상이 진짜 신호인가?" (발표 스토리 포인트)

**임베딩·어휘 기반 보상의 알려진 리스크**: Abdulhai et al. (NeurIPS 2025, *Consistently
Simulating Human Personas with Multi-Turn RL*)은 "유사도 지표는 미묘한 페르소나 모순을
감지하지 못할 수 있다"고 경고하고 LLM-judge 보상을 선택했다. 우리는 Judge Ceiling을 피하려고
반대 선택을 했으므로, **학습 전에 보상의 변별력을 데이터로 검증하는 게이트**(`rl/check_reward_sanity.py`)를 만들었다.

**실측 결과 (2026-07-04, 실제 SFT 데이터 40개/side + 중립 문장 8개, bge-m3):**

| 검증 항목 | 결과 | 수치 |
|---|---|---|
| LEFT anchor: 같은 페르소나 > 반대 페르소나 | ✅ PASS | own **0.762** > opposite 0.696 |
| LEFT anchor: 같은 페르소나 > 중립·양시론 | ✅ PASS | own **0.762** > neutral 0.597 |
| RIGHT anchor: 같은 페르소나 > 반대 페르소나 | ✅ PASS | own **0.748** > opposite 0.702 |
| RIGHT anchor: 같은 페르소나 > 중립·양시론 | ✅ PASS | own **0.748** > neutral 0.613 |
| coverage: 같은 질문 응답쌍 > 다른 질문 쌍 | ✅ PASS | **0.705** vs 0.194 |

→ **R_persona는 "우리 편 발언 / 반대편 발언 / 중립 발언"을 임베딩만으로 구분하고,
R_engagement는 논점 공유 여부를 구분한다.** 특히 중립 발언과의 분리(0.76 vs 0.60)가 가장 커서,
"중립 회귀 억제"라는 1차 목표에 보상이 잘 정렬되어 있음.

## 7. 엔지니어링 실측 (발표의 "구현 도전" 섹션용)

| 항목 | 내용 |
|---|---|
| 모델 | Kanana-2-30B-A3B-Instruct (DeepseekV3 아키텍처, MoE 128+2 experts, 활성 3B) |
| SFT 실측 | QLoRA 4bit, side당 60 step ≈ 6~6.5시간, loss 2.05→0.17 (L) / 2.03→0.14 (R) |
| transformers MoE 병목 | HF 구현이 128 expert를 Python loop로 순회 → GRPO 규모 생성(스텝당 64회×600토큰) 사실상 불가능 |
| 해결 | **vLLM 0.23 (fused MoE 커널 + multi-LoRA)**: base bf16 1벌 + LEFT/RIGHT LoRA 2개를 GPU 1장(97GB)에 얹어 배치 생성 |
| 기타 버그픽스 | transformers 4.57.6 고정(5.x는 MoE fused 재구현으로 4bit·LoRA 비호환), DeepSeek-V3 dtype 버그 몽키패치, MoE 라우터는 LoRA 대상에서 제외(peft ParamWrapper 비호환) |

### GRPO 본 학습 실측 결과 (2026-07-04 완료)

- **구성**: GPU 2장 (96GB급) — 학습(bf16+LoRA, ~60-76GB) / vLLM 롤아웃 서버(~84GB) 분리 (TRL server 모드)
- **시간**: self-play 트랜스크립트 240턴 생성 **8분** → GRPO side당 15스텝 × ~260초 = **~65분**
  → LEFT+RIGHT 순차 전체 **약 2.5시간** (vLLM 없이는 HF MoE loop 때문에 며칠 단위로 추정)
- **학습 안정성**: KL 0.009~0.015, clip 비율 2~4%, 발산 없음. 보상은 LEFT 1.0→1.26 범위에서
  약한 상승 경향, RIGHT ~1.0 유지 (1 epoch·lr 1e-5의 보수적 설정 — 성향을 더 강하게 밀려면
  iterative self-play 반복이 다음 단계)
- **MoE RL의 실무적 난점 (발표 언급용)**: vLLM(생성)과 HF(logprob 재계산)의 커널 차이로 expert
  라우팅이 갈려 토큰당 로그확률 차이가 평균 ~0.7-0.9 발생 → TRL의 vLLM importance sampling
  correction으로 보정됨을 확인. dense 모델에는 없는 MoE 고유 이슈
- **컴포넌트 로깅**: 학습 내내 persona ~0.51-0.59, diversity ~0.58-0.69, engagement 0.01-0.10
  (1라운드 턴은 상대 발언이 없어 정의상 0이라 배치 구성에 따라 낮게 보임 — 정상)

## 7.5 정성/정량 검증 결과 (2026-07-04, 발표 결과 섹션용)

**SFT vs GRPO** (동일 4주제 × 8라운드, `docs/eval/20260704_sft_vs_grpo_report.md`):

| 지표 | 결과 |
|---|---|
| 중립·양시론 표현 | **양쪽 모두 0회 / 64턴** — Default Bias(중립 회귀) 해결 (SFT 단계에서 달성) |
| 페르소나 유지 (anchor 유사도) | 8라운드 내내 ~0.77 일정 — 라운드가 가도 붕괴 없음 |
| 논점 커버리지 | GRPO가 개선: R2 0.547→**0.672**, R3 0.609→**0.703**. 발췌상 상대 프레임 직접 인용 반박 |
| 자기반복 (한계 발견) | 라운드 5+에서 둘 다 Jaccard 0.8~0.9 (사실상 복붙) — 학습이 3라운드까지만 본 분포 밖 구간 |

**Synthesizer 하이브리드** (중립 종합자가 3라운드마다 개입해 미다룬 하위 쟁점으로 질문 교체
+ 종료 시 최종 종합, `docs/eval/20260704_grpo_vs_hybrid_report.md`):

| 라운드 | GRPO 단독 자기반복 | +Synthesizer | 효과 |
|---|---|---|---|
| R4 (개입 직후) | 0.593 | **0.250** | -58% |
| R5 | 0.875 | **0.378** | -57% |
| R7 (2차 개입 직후) | 0.819 | **0.274** | -67% |

→ **학습(R_novelty/R_diversity)이 분포 밖 구간에서 못 잡는 반복을 inference-time 개입이 차단**
— 슬라이드 11 "Diversity Pruning"의 발전된 구현으로 발표 가능. Synthesizer는 판정 없이
정리·전환·종합만 수행 (Judge Ceiling 대응 설계 유지). 최종 종합은 목업 패널 구조
(핵심 쟁점/양측 논거/합의점/남은 쟁점)를 그대로 재현.

## 8. 한계 및 향후 과제 (질문 대비)

- **Diversity Pruning (inference-time, 중간발표 슬라이드 11)**: 원안(중복 응답 폐기) 대신
  **Synthesizer 중간 개입(쟁점 전환)으로 구현** — §7.5 실측 참고. 응답을 버리지 않고 화두를
  바꾸는 방식이라 정보 손실이 없음.
- **R_grounding**: RAG 파이프라인 부재로 비활성. AI-Hub 국회 회의록 + BM25로 활성화 가능.
- **Synthesizer DPO 학습**: 프롬프트 기반 Synthesizer(중간 개입 + 최종 종합)는 구현·검증
  완료(§7.5). 슬라이드 12의 DPO 학습(pseudo-preference: 균형 종합 vs 편향 종합)은 향후 과제.
- **Belief Entrenchment**: 정면 대응하지 않음 (R_diversity의 부분 완화 효과만).
- **평가 계획**: 학습 전/후 동일 주제 10라운드 토론에서 (a) 라운드별 스탠스 점수(0~10) 유지력,
  (b) 중립 표현("양쪽 다 일리가", "균형 잡힌" 등) 빈도, (c) judge 기반 prompt-to-line
  consistency (Abdulhai et al. 방식) 비교.
